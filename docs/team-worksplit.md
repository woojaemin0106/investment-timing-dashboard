# 타이밍 대시보드 분업 기준

본 문서는 해커톤 기간 동안의 역할 분담과 작업 경계를 고정하기 위한 기준 문서입니다.

## 역할 분담

- 본인(Codex): 구조/데이터/API/분석
- 팀원 A: Overview/핵심 차트/UI
- 팀원 B: Detailed/Anomaly/필터/상태

## 책임 범위 상세

### 1) Codex (구조/데이터/API/분석)

- 프로젝트 폴더 구조/모듈 경계 설계
- 데이터 모델 정의 및 API 클라이언트/어댑터 구성
- 공통 분석 로직(지표 계산, 신호 산출, 통계 유틸) 작성
- 데이터 연동 실패/예외 처리 정책 기본안 작성

### 2) 팀원 A (Overview/핵심 차트/UI)

- 메인 Overview 화면 레이아웃 구성
- 핵심 차트 컴포넌트 구현 및 시각화 튜닝
- 상단 요약 카드/핵심 지표 영역 UI 완성
- 반응형/기본 인터랙션(로딩/빈 상태) 처리

### 3) 팀원 B (Detailed/Anomaly/필터/상태)

- 상세 분석 화면(Detailed) 구성
- 이상치(Anomaly) 탐지 결과 표현 UI/흐름 구현
- 기간/조건 필터 컴포넌트 구현
- 상태 처리(loading/empty/error/success) 표준화 적용

## 인터페이스 경계(협업 포인트)

- Codex -> 팀원 A/B
  - 화면에서 사용할 데이터 타입/응답 스키마 공유
  - 차트/상세뷰에서 공통으로 쓰는 분석 결과 포맷 제공
- 팀원 A/B -> Codex
  - UI에서 필요한 데이터 요구사항 확정
  - 필터/차트 상호작용 이벤트 스펙 확정

## 진행 규칙

- 브랜치: `feature/*`에서 작업 후 `develop`으로 PR
- PR은 템플릿 기준으로 작성하고 체크(`pr-checks`) 통과 후 머지
- 공통 타입/분석 로직 변경 시 팀원 A/B에게 즉시 공유
